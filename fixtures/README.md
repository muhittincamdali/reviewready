All projects were made on 28 October 2026 on a Mac (Apple silicon) with Xcode 27.1 (27A9275).
Only the files reviewready reads and the manifests that explain them are kept: no `node_modules`,
`Pods`, Android folders, build output, test targets or IDE files. Dependencies in the package.json
and pubspec.yaml files are declared, not installed. The App Store icons of the native fixtures
and of expo-58-camera are written by [scripts/fixture-icons.ts](../scripts/fixture-icons.ts):
1024 × 1024, solid navy, with a transparent band where the icon should fail.

The React Native project file is the template's before `pod install`. React Native's
`pod install` adds `PrivacyInfo.xcprivacy` to Copy Bundle Resources (privacy manifest
aggregation), which is what the RVW702 finding tells the reader to commit.
