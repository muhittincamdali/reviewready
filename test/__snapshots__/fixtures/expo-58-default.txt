         app.json
         app.json sets neither ios.config.usesNonExemptEncryption nor
         ios.infoPlist.ITSAppUsesNonExemptEncryption, so App Store Connect asks the export
         compliance questions for every build.
         Fix: [A] Declare the app's encryption in app.json
         Source:
         https://developer.apple.com/documentation/bundleresources/information-property-list/itsappusesnonexemptencryption

WARNING  RVW701 No privacy manifest
         app.json
         app.json has no ios.privacyManifests, so prebuild writes no privacy manifest for the app.
         Fix: [B] Add ios.privacyManifests to app.json
         Source: https://developer.apple.com/documentation/bundleresources/privacy-manifest-files

How to fix

[A]      Declare the app's encryption in app.json
         1. Set expo.ios.config.usesNonExemptEncryption to false if the app uses no encryption or
            only exempt encryption such as HTTPS, or to true and follow Apple's documentation
            otherwise.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/export-compliance.md

[B]      Add ios.privacyManifests to app.json
         1. Add expo.ios.privacyManifests with NSPrivacyAccessedAPITypes (and the data types the app
            collects); prebuild writes them into PrivacyInfo.xcprivacy.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/privacy-manifest.md
