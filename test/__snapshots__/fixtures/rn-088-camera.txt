How to fix

[A]      Add the key to Info.plist
         1. Add the key to the target's Info.plist with one sentence that says what the app does
            with the data, for example: <key>NSCameraUsageDescription</key><string>Scan the barcode
            on a receipt to add it to your expenses.</string>
         2. If the app never uses this feature, remove the code or the package that uses it instead.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/purpose-strings.md

[B]      Write a one-sentence string
         1. Make the value a <string> of one complete sentence that says what the app does with the
            data, well under 4,000 bytes.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/purpose-strings.md

[C]      Add the 1024 × 1024 image
         1. Open the asset catalog in Xcode, select the app icon and drop a 1024 × 1024 PNG into the
            App Store (or single-size iOS) slot, or add an Icon Composer .icon file with the name
            the target builds (ASSETCATALOG_COMPILER_APPICON_NAME).
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/app-icon.md

[D]      Declare the app's encryption
         1. If the app (with its libraries) uses no encryption, or only the encryption built into
            the operating system such as HTTPS through URLSession, add
            <key>ITSAppUsesNonExemptEncryption</key><false/>.
         2. If it uses non-exempt encryption, set it to <true/> and add
            ITSEncryptionExportComplianceCode with the code Apple gives you after reviewing your
            documentation.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/export-compliance.md

[E]      Add the file to the app target
         1. Select PrivacyInfo.xcprivacy in Xcode, open the File inspector and tick the app target
            under Target Membership, so it appears in Build Phases > Copy Bundle Resources.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/privacy-manifest.md
