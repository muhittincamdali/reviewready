How to fix

[A]      Set the text in app.json
         1. Set the key under expo.ios.infoPlist in app.json, or pass the text to the package's
            config plugin option, with a sentence that says what the app does with the data.
         2. Run npx expo prebuild --clean (or the next EAS Build) so the native Info.plist gets it.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/purpose-strings.md

[B]      Build with Xcode 26 or later
         1. Change the pinned version to Xcode 26 or later (for example 27.1) in the file and line
            the finding names, and use a runner or build image that has it.
         2. Fix the build warnings and errors the newer SDK reports before the next upload.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/xcode-and-ios-minimums.md

[C]      Pass your own text to the config plugin
         1. Add the plugin to expo.plugins with its permission option, for example ["expo-camera", {
            "cameraPermission": "Scan a receipt to add it to your expenses." }], or set the key
            under expo.ios.infoPlist.
         2. Set the option to false instead if the app never uses that permission: the plugin then
            leaves the key out.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/purpose-strings.md

[D]      Add ios.privacyManifests to app.json
         1. Add expo.ios.privacyManifests with NSPrivacyAccessedAPITypes (and the data types the app
            collects); prebuild writes them into PrivacyInfo.xcprivacy.
         https://github.com/muhittincamdali/reviewready/blob/main/docs/guides/privacy-manifest.md
